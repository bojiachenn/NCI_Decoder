## 2. 變更摘要

**Phase A — Python 同步網頁版的修正**（`web/tests/known_diffs` 原本列了 102 個案例）

| 區域 | 主要修正 |
|---|---|

| `Nxp_pkg/RF_Management.py` | FIELD_DETECT_NTF 的 offset 與 bit 3；NAK_PRESENCE_RSP 改用 NXP 的 status 表 |
| `Nxp_pkg/Proprietary.py`、`HDLL.py`、`__ctrl__.py` | COLD_RESET_CMD、TEST_PRBS_CMD、L1_DEBUG_NTF、RF_SPC phase、TXLDO／VDDPA 改用 base 16；HDLL 的 chunk bit、未知 op code、CRC-16-CCITT-FALSE 驗證 |
| `range_lookup.py` | 新增 `lookup()`：先精確比對，查不到再找 `XX-YY` 範圍 key |
| `__table__.py`（兩份） | `tbl_rf_commu_para_id['02']` 的表號由 131 改為 132；刪除已註解掉的錯誤版 `tbl_tlv_type` |

**Phase B／C — 兩邊同時修正**：
- NFC-DEP Poll 補讀 Data Exchange Length Reduction（規範 Table 102）。
- NXP CORE_RESET_NTF 依 Manufacturer Info 的長度解析。
- L2_DEBUG CMA 資料不再截斷在 9／8 bytes。
- APDU_LOGGING_NTF 遇到未知 Category 時，把剩餘 bytes 印成 APDU Data。
- HDLL：Session State 未知值顯示 RFU；CHECK_INTEGRITY 中只有 code section 的列也會印出。
- 1-octet bit-field 參數的 Len > 1 時，只解第 1 個 octet 並加印警告。
- Conn ID 遮罩為低 4 bits（forum 版與 NXP 自己的 CORE_CONN_CREATE_RSP 都已處理）。
- `6F 1C` LOW_POWER_TAG_REMOVAL_NTF 完成註冊。
- 改為 little-endian：A009、RF_GET_TRANSITION_RSP。
- 依 NXP UM 修正（2026-10-16）：
  - **A094**：Bit[0:3] 為 timeout 值；Bit[7] = 1 表示單位為秒；Bit[4:6] 為 RFU。Len > 1 時只解第 1 octet，並加印警告。
  - **A098**：Ref. field strength 取 byte3 的 Bit[4:7]。
  - **DPC_HELPER current**：12-bit，`byte0 + (byte1 & 0x0F)*256`。
  - 10-15 曾把這三項改成整個 value 以 little-endian 解讀，經 UM 確認是錯的，已改回。
- AST_LOOP 不改邏輯，只加註解。

**Phase D**：`nfc_forum_2_3_pkg/RF_Management.py` 修掉 4 類 crash：浮點數被當成 range、`p_payload` 未定義、`val_payload` 未定義、trigger 04 的 `n/2`。

**Phase E**：
- `Decoder.py` 不再對 log 行做 cp950 重新解碼。
- `_d.txt` 改以 UTF-8 寫出。
- filter 為空白時退回 `remain_all`。
- 每個檔案開始時呼叫 `Decoder_Main.reset_state(vendor)`，由 `Nxp_pkg/__ctrl__.reset_state()` 還原 7 個全域狀態。
- stdout 不是 UTF-8 時，改用 `reconfigure(encoding="utf-8")`。

## 4. 已知限制與注意事項

1. **網頁版刻意保留的 7 處差異**：payload 截斷時，網頁版印 `Error: Payload too short …`，Python 印空欄位或讀取時出錯。若要讓 Python 一致，需要在每個 handler 加上邊界檢查，本輪不做。
2. ✅ **已依 NXP UM 確認並修正（2026-10-16）**：A094、A098、DPC_HELPER_RSP Current 的定義見第 2 節。DPC 以使用者提供的驗收向量驗證。
3. **AST_LOOP**：OID 0x32 的 READ_TXLDO_CURRENT／READ_RSSI 分支仍然執行不到，已在程式中加註說明。
4. **ST 專屬指令、GID 3／4** 仍未支援，本輪不在範圍內。
5. **NCI 2.3** 只修了 crash，仍未接上 dispatch。
